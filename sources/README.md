# Data sources and attribution

This is the source-approval register. Add an entry here before importing data.

- **OEM sources:** official India product pages, brochures, owner manuals and technical specifications. Record the exact URL and date checked.
- **Government sources:** use only for fields actually present. Do not infer trim-level specifications from registration data.
- **Licensed providers:** retain evidence of the licence and permitted redistribution scope.
- **Secondary websites:** research leads only unless their terms explicitly allow reuse. Do not bulk-copy their catalogue data.

Each vehicle and variant must include source name, source URL, verification date, status and (where applicable) licence/permission details. Keep notes on which fields the source supports.

## Current status

No external dataset has yet been approved for bulk import. The canonical catalogue is intentionally empty until sources and reuse rights are confirmed.
